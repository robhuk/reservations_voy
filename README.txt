XC Reservation List PWA

Train details at the top:
- Enter the four-character headcode (for example 1V50); it is displayed in bold and uppercased automatically.
- Date defaults to today's local date and can be changed.
- Headcode and date are included in copied tables, CSV, email and PDF output.

Workflow: enter train details, paste Genius reservations, process, review the whole-train table, then copy/download/email/print.

Host over HTTPS (for example GitHub Pages) for PWA installation and offline support. Pasted text, processed rows, headcode and date are saved in browser localStorage and are not removed by service-worker cache updates.
